# DAWNFOLD source layers

Generated with the built-in image-generation tool on 2026-08-29. These are original source layers for the DAWNFOLD visual system; none use artist portraits, official tour/album artwork, logos, or copied promotional compositions.

## Transparency note

The built-in generator returned RGB PNGs with a baked checkerboard after explicit transparent-background requests. Visual inspection and `sips -g hasAlpha` rejected those outputs (`hasAlpha: no`). The approved fallback is an intentionally uniform Night Black (`#050507`) field for `moon-surface.png`, `fog-night.png`, and `fog-dawn.png`. Future scene composition must place them over the same `--night` ground, circle-mask the moon where needed, and use `screen`/`lighten` blending for fog rather than treating them as alpha layers.
