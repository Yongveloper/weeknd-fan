# The Weeknd 고양 콘서트 팬 가이드 설계

- 상태: 대화 설계 승인·작성 문서 검토 대기
- 작성일: 2026-08-29
- 대상 공연: 2026년 10월 7–8일 고양종합운동장
- 디자인 콘셉트: **DAWNFOLD**

## 1. 제품 정의

2026년 The Weeknd 고양 공연을 찾는 사람에게 팬이 건네는 비공식·비영리 디지털 팜플렛이다.

이 사이트의 목적은 정보를 많이 쌓는 것이 아니다. 유명한 곡 몇 개만 아는 관객도 The Weeknd를 조금 더 이해하고, 공연장에서 음악과 무대의 의미를 더 깊게 느끼며, 당일 필요한 정보를 빠르게 찾게 하는 것이 목적이다.

핵심 문장:

> The Weeknd의 영화적인 밤을, 한국 팬의 따뜻한 공연 팜플렛으로 펼쳐내는 경험.

## 2. 목표와 성공 기준

### 목표

1. 처음 온 관객이 3분 안에 The Weeknd와 이번 투어의 핵심을 이해한다.
2. 공연 방문자가 10초 안에 날짜, 시간, 장소, 교통, 준비 정보를 찾는다.
3. 예상 셋리스트가 곡, 앨범, 세계관, 떼창, 관람 포인트를 연결한다.
4. 코어 팬은 전체 커리어와 출처를 참고하고 공연 후 내용을 복기할 수 있다.
5. 짧은 기간이라도 캡처·저장·공유하고 싶은 화면으로 자연스러운 확산을 만든다.

### 성공 기준

- 첫 화면에서 공연 일시·장소와 두 개의 핵심 진입점을 즉시 인식할 수 있다.
- 핵심 입문 콘텐츠의 기본 읽기 시간은 3분을 넘지 않는다.
- 핵심 사실에는 출처, 확인 날짜, 정보 상태가 표시된다.
- 셋리스트는 `공식 확정`으로 오해할 수 없게 표시된다.
- 주요 화면은 모바일에서 끊김 없이 작동하고 모션 없이도 모든 정보를 읽을 수 있다.
- 카카오톡·X 등으로 공유했을 때 사이트의 정체성이 보이는 미리보기와 저장용 이미지가 표시된다.

- 고양종합운동장 교통·귀가·준비 안내
- 팬 운영자의 짧은 추천과 감상

## 6. 정보 신뢰 체계

모든 핵심 정보에는 다음 상태 중 하나를 붙인다.

- `공식 확정`: The Weeknd, Live Nation, 현대카드, NOL 티켓, 공공기관 원문으로 확인
- `공연 후 확인`: 공연 이후 복수 기록이나 공식 채널로 교차 확인
- `반복 패턴`: 최근 2026년 공연 세 건 이상에서 동일하게 관측
- `예상 · 보장 아님`: 반복 패턴을 바탕으로 한 고양 공연 추정
- `미공개 · 확인 필요`: 주최 측의 추가 안내가 필요한 정보

각 항목은 출처 URL, 출처 이름, 마지막 확인 날짜를 함께 보관한다.

## 8. The Weeknd 콘텐츠 원칙

### 전체 작품 구분

정규 앨범:

1. `Kiss Land` (2013)
2. `Beauty Behind the Madness` (2015)
3. `Starboy` (2016)
4. `After Hours` (2020)
5. `Dawn FM` (2022)
6. `Hurry Up Tomorrow` (2025)

별도 분류:

- 2011 믹스테이프: `House of Balloons`, `Thursday`, `Echoes of Silence`
- 2012 컴필레이션: `Trilogy`
- 2018 EP: `My Dear Melancholy,`
- 컴필레이션: `The Weeknd in Japan`, `The Highlights`
- 라이브: `Live at SoFi Stadium`

### 최근 앨범 3부작

`After Hours → Dawn FM → Hurry Up Tomorrow`는 공식적으로 연결된 앨범 3부작이다.

안전한 설명 범위:

- `After Hours`: 밤의 쾌락, 고립, 후회, 자기파괴를 영화적 캐릭터로 표현
- `Dawn FM`: 가상 라디오를 통해 후회와 집착을 되짚는 전환 구간
- `Hurry Up Tomorrow`: 명성, 페르소나, 공포, 자기대면을 마무리하는 최종장

`사망 → 연옥 → 환생`처럼 단일한 사건 줄거리는 공식 설정으로 단정하지 않는다. 팬 해석으로만 소개한다.

### 나무위키 사용 원칙

나무위키는 콘텐츠 후보, 팬 용어, 누락 탐색을 위한 보조 자료다. 핵심 사실의 최종 근거로 사용하지 않는다.

- 원문 문장과 이미지를 복사하지 않는다.
- 판매량, 차트, 수상, 영향력 수치는 공식 최신 자료로 재검증한다.
- 사생활, 친분, 추측성 영향 관계는 공연 가이드에서 제외한다.
- 과장된 최상급 표현은 사용하지 않는다.

## 9. 디자인 콘셉트: DAWNFOLD

### 정의

> The Weeknd의 밤에서 새벽으로 펼쳐지는 디지털 콘서트 팜플렛.

DAWNFOLD는 `Digital Pamphlet`, `Night to Dawn`, `Cinematic Highlight`, `Fan-made Emotion`을 결합한다.

전체 탐색은 읽기 쉬운 팜플렛 경험이 맡고, 첫 진입·셋리스트 전환·공연장 도착 같은 중요한 순간에만 네온 도시와 런웨이의 몰입형 연출을 사용한다.

### 색상

- Night Black: `#050507`
- Deep Red: `#A61F27`
- Cobalt Blue: `#2F63D8`
- Dawn Amber: `#E6A359`
- Paper Ivory: `#F0E8DA`
- Chrome Mist: `#D7D8DC`

색은 단순 테마가 아니라 사용 흐름을 설명한다.

```text
검정 표지
  → 딥 레드의 밤과 The Weeknd 입문
  → 코발트 블루의 셋리스트·네온 런웨이
  → 앰버빛 새벽과 고양 공연 실용 정보
```

### 시각 언어

- 달, 수평선, 안개, 필름 그레인, 빛 번짐
- 대각선 마스크와 깊이 있는 레이어
- 강한 영문 디스플레이 타이포그래피와 절제된 한국어 본문
- 사진과 공식 로고를 복제하지 않는 추상적 도시·빛 모티프
- 반복되는 직사각형 카드, 둥근 박스, 대시보드형 그리드 배제
- 섹션은 테두리 대신 빛, 색, 수평선, 여백으로 구분

### 전환과 애니메이션

- 팜플렛의 면이 대각선으로 펼쳐진다.
- 붉은 빛이 번지고 레이저 블루가 화면을 가로지른다.
- 달과 수평선이 이동하며 밤에서 새벽으로 바뀐다.
- 셋리스트 진입 때만 런웨이 원근과 네온 도시 깊이를 사용한다.
- 전환은 450–700ms 안에서 끝나며 읽는 동안에는 움직임이 멈춘다.
- 지속적인 패럴랙스와 장식성 자동재생은 최소화한다.

### 접근성·성능

- `prefers-reduced-motion`에서는 공간 이동을 페이드와 즉시 전환으로 대체한다.
- 애니메이션이 없어도 정보와 순서를 완전히 이해할 수 있어야 한다.
- 모바일은 무거운 WebGL 3D 대신 CSS 마스크, SVG, 블러, 2.5D 레이어를 사용한다.
- 본문 대비는 WCAG AA를 만족한다.
- 공식 미디어 임베드는 지연 로딩하고 실패하면 원문 링크를 제공한다.

커뮤니티나 로그인 없이 저장·캡처·공유 가능한 결과물을 만든다.

- 서버 저장과 개인정보 수집 없음

### Setlist Card

- 최근 투어 기준 예상 목록을 포스터 비율로 저장
- Tokyo, Jakarta, Singapore 공연 이후 갱신 버전 표시
- `예상 · 보장 아님` 상태를 이미지에도 포함

### 공유 미리보기

- 카카오톡·X 등에서 표시할 전용 OG 이미지
- 공연 날짜, 장소, 사이트 목적을 한눈에 표현
- 공식 사이트로 오해할 로고나 표현 사용 금지

### 검색·발견

- 한국어 검색어에 맞는 명확한 제목과 설명
- 공연일, 장소, 공식 링크를 구조화된 데이터로 제공
- 셋리스트 갱신 시 마지막 확인 날짜를 노출
- 익명 집계만 사용하는 경우 페이지 조회와 공유 버튼 동작만 측정하며 개인 식별자를 만들지 않는다.

## 11. 저작권·출처 정책

- 공식 사이트가 아닌 비공식·비영리 팬 가이드임을 모든 주요 진입점에서 밝힌다.
- The Weeknd, XO, 현대카드, Live Nation과의 공식 제휴를 암시하지 않는다.
- 가사 전문 또는 장문의 가사를 게시하지 않는다.
- 무단 공연 영상, 팬 촬영물, 언론 사진, 앨범 아트를 복제하지 않는다.
- 가능한 경우 공식 YouTube·Spotify 임베드와 원문 링크를 사용한다.
- 인용은 비평·설명에 필요한 짧은 범위로 제한하고 출처를 표시한다.
- 자체 제작한 추상 그래픽과 타이포그래피를 기본 시각 자산으로 사용한다.

## 12. 콘텐츠·데이터 구조

첫 버전은 정적 콘텐츠 중심으로 구현한다. 로그인, 데이터베이스, 실시간 서버가 필요하지 않다.

각 콘텐츠 항목의 공통 필드:

- `title`
- `summary`
- `body`
- `status`
- `lastVerifiedAt`
- `sources[]`
- `relatedAlbums[]`
- `relatedSongs[]`
- `spoilerLevel`

셋리스트 항목 추가 필드:

- `expectedOrder`
- `songTitle`
- `album`
- `liveNote`
- `singAlongNote`
- `confidence`

데이터 흐름:

```text
운영자가 출처와 콘텐츠 갱신
  → 정적 빌드에서 페이지·메타데이터 생성
  → 사용자가 읽고 펼쳐보기·공유 카드 생성
  → 선택값은 브라우저에서만 처리하고 서버에 저장하지 않음
```

## 14. 오류·실패 처리

- 외부 임베드 실패: 공식 원문 링크와 곡 제목을 남긴다.
- 공식 정보 변경: 이전 값 대신 최신 확인값과 갱신 날짜를 표시한다.
- 출처 불일치: 더 보수적인 표현을 사용하고 양쪽 출처를 공개한다.
- 셋리스트 데이터 부족: 신뢰도를 낮추고 예상 범위를 축소한다.
- JavaScript 비활성화: 핵심 텍스트·공연 정보·출처 링크는 그대로 읽을 수 있다.
- 공유 이미지 생성 실패: 기본 OG 이미지와 텍스트 공유 링크로 대체한다.

## 15. 검증 기준

### 콘텐츠

- 정규 앨범, EP, 컴필레이션 분류가 공식 레이블 자료와 일치한다.
- 앨범 3부작의 공식 설명과 팬 해석이 시각적으로 구분된다.
- 공연 핵심 정보는 Live Nation, 현대카드, NOL 티켓 중 두 곳 이상으로 확인한다.
- 세트리스트는 최근 공연 세 건 이상을 비교하고 crowd-sourced 데이터임을 표시한다.

### UX

- 처음 방문자가 10초 안에 공연 날짜·장소·주요 진입점을 찾는다.
- 모바일에서 교통·준비물·귀가 정보가 두 번 이내의 동작으로 열린다.
- 셋리스트 전체는 기본 접힘 상태이며 사용자가 명시적으로 펼친다.
- 깊은 콘텐츠를 읽지 않아도 기본 공연 준비가 가능하다.

### 디자인·접근성

- 직사각형 카드 반복 없이도 섹션 경계가 분명하다.
- 모션 감소 모드에서 기능과 정보 손실이 없다.
- 키보드만으로 모든 펼쳐보기와 링크를 사용할 수 있다.
- 본문 대비, 포커스 표시, 터치 영역이 접근성 기준을 충족한다.
- 주요 모바일 화면에서 애니메이션이 부드럽게 실행되고 스크롤을 방해하지 않는다.
