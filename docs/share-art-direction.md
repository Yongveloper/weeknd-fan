# 공유 이미지 아트 디렉션

2026-09-18 사용자가 제공한 `자산 3.png`(가로형 D-day 티켓)와 `자산 4.png`(세로형 셋리스트 포스터)를 최신 디자인으로 사용한다. 이전의 Canvas 조합 표지와 세로형 티켓을 대체한다. PC와 모바일은 같은 가로형 티켓을 사용하며 모바일용 세로 티켓은 제공하지 않는다.

## 원본과 웹 표시

원본 PNG는 바이트 변경 없이 `public/downloads/`에 보존하고 각 도구 화면에 다운로드 링크를 둔다. 아래 SHA-256은 원본 파일과 등록 파일을 직접 비교해 확인했다.

| 입력       | 등록 원본                                        | 해상도    | SHA-256                                                            |
| ---------- | ------------------------------------------------ | --------- | ------------------------------------------------------------------ |
| 자산 3.png | `public/downloads/into-dawn-ticket-original.png` | 6902×3301 | `14478db22f1100c502b5b520cb1064959342483f38aa84c4e9998a42acb830b4` |
| 자산 4.png | `public/downloads/into-dawn-poster-original.png` | 4651×7054 | `b718bce25708c9c69952c955c38e426d43cd30fa0d0af0bf577db9e5dfc29a6c` |

화면과 공유 JPEG에는 동일한 비율로 축소한 WebP를 쓴다. 티켓 표시 에셋은 1725×825, 포스터는 1080×1638이며 둘 다 quality 85로 변환했다. 큰 원본 파일은 미리 불러오지 않고 다운로드 링크를 선택할 때만 요청한다. 페이지 이미지 예산은 기존대로 유지하고 원본 다운로드에만 별도 합계 8 MiB 한도를 적용한다.

## 티켓

- 출력: 가로형 2070×990 JPEG. 원본의 검정·아이보리 양면 구성, 일식, 붉은 제목, 번호와 정적인 라벨을 그대로 표시한다.
- 기존 날짜 선택과 서로 다른 세 곡 선택 기능을 유지한다. D-day, 날짜와 세 곡 영역만 원본의 빈 종이 질감을 이용해 덮은 뒤 선택값을 그린다.
- D-day와 날짜는 Anton, 곡명은 Noto Sans KR Variable로 그린다. 이 편집 가능한 글자는 원본의 고정 글자를 픽셀 단위로 복제하지 않는다. 원본 그대로의 고정 티켓은 원본 PNG 링크로 받을 수 있다.
- 긴 곡명은 글자 크기를 줄여 칸 안에 넣으며 가로로 찌그러뜨리지 않는다.
- 모바일도 동일한 가로형 아트워크를 사용한다. 작은 미리보기와 펼치기 기능, 선택값 보존, 키보드 조작을 유지한다.

## 포스터

- 출력: 세로형 1080×1638 JPEG.
- 첨부 아트워크 전체를 표시한다. 곡명·38곡 순서·레이아웃·정적인 `UPDATED 2026.08.29`를 다시 조판하지 않는다.
- 포스터는 승인된 고정 아트워크다. 향후 셋리스트 데이터가 달라지면 새로운 포스터 원본도 별도로 교체해야 한다.
- 메인 예상 셋리스트의 사실 구분, 콘텐츠와 출처의 확인 날짜는 변경하지 않는다.

## 동작과 검수

이미지는 브라우저 안에서 생성하며 선택값을 서버·쿠키·분석 도구로 보내지 않는다. JPEG 다운로드, 지원되는 브라우저의 파일 공유, 텍스트 공유와 실패 안내를 유지한다. 미리보기와 저장은 같은 그리기 명령을 사용한다.

헤드리스 Chrome에서 PC 1440×1000, 모바일 390×844로 티켓과 포스터를 확인했다. 세 곡 선택을 반영한 티켓과 포스터 캔버스를 직접 보고 원본의 구성·비율·글자·배치와 비교했으며 가로 넘침과 페이지 오류는 없었다. 로컬 검수 화면은 무시되는 `tmp/final-art-review/`에 보관한다.
