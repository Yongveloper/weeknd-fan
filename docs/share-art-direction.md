# 공유 이미지 아트 디렉션

2026-09-17 최신 승인 범위: `/share/setlist/`와 `/share/ticket/`의 미리보기·저장 이미지를 평면 일식 마크를 쓰는 공통 포스터 구성으로 통일한다. 이 문서는 두 공유 이미지와 관련 도구 화면에 한정되며, 이전 문서의 공유 아트워크 변경 금지·홈 실사 에셋 재사용·`예상 · 보장 아님` 보존 지시보다 우선한다. 메인 웹 셋리스트의 사실 구분과 콘텐츠·출처의 확인 날짜는 변경하지 않는다.

## 공통 표지

- 출력은 세로 1080×1350 JPEG다. `src/lib/share/cardDesign.ts`가 크기, 팔레트, 서체, 공통 표지와 푸터의 기준이다.
- 홈의 실사 일식·구름 에셋은 사용하지 않는다. 검정 바탕에 아이보리 활자와 앰버 강조, 얇은 구분선을 둔다. 오른쪽 일식 마크는 거의 가려진 태양의 수평 오른쪽 3시 방향으로 노출된 앰버 면으로 구성한다. Canvas2D에서 중심 (862, 300), 반지름 114px인 태양과 왼쪽 14px만 수평으로 이동한 같은 크기의 가림 원 사이에 드러나는 면만 그린다. 가장 넓은 부분은 약 14px이며 양 끝은 가늘게 닫힌다. 가림 원과의 교점을 직접 계산해 원 둘레에 클리핑 잔선이 생기지 않게 한다. 기존의 작은 흰색 광점은 제거하고 앰버 면의 크기·위치·곡선은 유지한다. 완전한 원형 테두리나 흐릿한 빛 번짐은 추가하지 않는다.
- 상단의 INTO:DAWN은 글자 높이의 상하단에 맞춘 두 원으로 쌍점을 그린다. 하단 로고에도 같은 규칙을 적용한다. 상단의 INTO:DAWN과 `GOYANG / 2026`, THE WEEKND / AFTER HOURS / 윤곽선 TIL DAWN을 공통으로 사용한다. THE WEEKND는 60px·기준선 174px, AFTER HOURS와 TIL DAWN은 모두 124px이며 기준선은 각각 310px·409.4px다. 아티스트명을 독립된 위계로 키우고, 투어 두 줄은 같은 글자 크기와 좌측 정렬로 묶고, 자연스러운 글자 폭(약 501px·352px)을 유지한다. 이전의 실제 줄 사이 간격 약 10.36px를 보존하며, 제목 블록 위아래에는 약 47px·46px의 여백을 둔다. 아티스트와 투어 제목은 더 넓은 여백으로 분리하고 투어 두 줄은 가까운 하나의 블록으로 읽힌다. TIL DAWN은 채우기 없는 2px 윤곽선으로 그린다. 표지 하단선은 456px이다.
- 공통 여백은 좌우 74px이며 본문도 같은 검정 바탕에서 곡명과 날짜를 또렷하게 읽게 한다. 하단에는 INTO:DAWN과 UNOFFICIAL FAN GUIDE를 함께 표시한다. 두 이미지에 별도 팔레트나 표지를 도입하지 않는다.

## 이미지별 내용

| 도구            | 구성                                                                                           | 보존 조건                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 셋리스트 포스터 | EXPECTED SETLIST, 현재 예상 38곡의 번호·곡명을 2단으로 배치, 곡 수, 기존 데이터의 UPDATED 날짜 | 전체 곡명·순서·업데이트 날짜를 유지하고 `예상 · 보장 아님`은 포스터와 도구 화면에서 제거한다. |
| D-day 티켓      | D-DAY TICKET, 선택한 관람일·D-day, MY THREE SONGS 아래 세 곡, 하단 점선                        | 관람일 선택과 서로 다른 세 곡 선택을 유지한다.                                                |

긴 곡명은 가로로 찌그러뜨리지 않고 사용 가능한 너비에 맞춰 글자 크기를 줄인다. 미리보기와 다운로드는 같은 그리기 명령을 사용하며 글꼴을 불러온 뒤 렌더링한다.

셋리스트 38곡은 기존과 같은 2단·32px 행간·약 25px 글자 크기를 유지한다. 첫 행 기준선은 584px, 마지막 행은 1160px이며, UPDATED 기준선은 1232px이다. 표지의 여백을 늘리면서 곡 목록의 가독성을 줄이지 않는다. 티켓의 날짜·D-day와 세 곡도 기존 글자 크기를 유지하고 아래로 16px 옮겨 공통 표지와 호흡을 맞춘다.

## 기능과 개인정보

기존 JPEG 다운로드, 지원 브라우저의 파일 공유, 텍스트 공유 문구 복사, 기본 공유 이미지 대체 경로, 상태·오류 안내를 유지한다. 티켓은 서로 다른 세 곡을 선택해야 저장할 수 있다. 이미지는 브라우저 안에서만 생성하며 선택값은 저장하지 않는다. 승인된 `예상 · 보장 아님` 제거 외에는 데이터·라벨·선택 기능·개인정보 동작을 바꾸지 않는다. EXPECTED SETLIST와 비공식 팬 가이드 표시는 유지한다.
