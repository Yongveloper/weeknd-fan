# 사이버 팜플렛 수정 검수

검수 완료 기준: 2026-09-16. 로컬 빌드, Node 22.14.0.

## 적용 범위

홈페이지 정보 진입 구조 및 지면 배치, 일식 이후에도 남는 구름 조명과 움직임. 콘텐츠 원본, 상세 라우트, 공유 기능 데이터는 변경하지 않았다. 기존 v8 영상과 구름/안개 이미지를 재사용했다. 신규 이미지 생성 없음.

- 일식 원판 opacity는 하단에서 0, 구름 opacity 변수는 0.5, 조명 스크롤 계수는 0.85.
- 기본 구름층과 조명층은 같은 부모에서 움직여 위치를 공유한다.
- 수평·수직 움직임은 각각 독립 주기. 하단에서도 실제 transform/translate 값이 변함을 두 화면 크기에서 확인했다.
- 메인 목차의 8개 링크로 앨범 타임라인, 예상 셋리스트, 곡별 관람 포인트, 고양 가이드, 공식 공지, 출처, 포스터와 D-day 티켓에 접근한다.
- 모든 기존 홈 섹션과 상세 콘텐츠를 보존했다.

## 실행한 검사

- lint, format:check, Astro check: 통과. 기존 TypeScript ESLint deprecated 힌트 1건.
- 단위 테스트: 60 통과. 최초 샌드박스 실행에서 브라우저 권한 문제로 2개 실패했으며, 브라우저 실행 권한을 제공한 재실행에서 전체 통과.
- 정적 빌드: 7개 라우트 통과.
- 용량 검사: 통과. 전체 JS gzip 10.1 KiB / 75 KiB, 래스터 874.9 KiB / 1300 KiB. 영상 파일 용량은 이 래스터 수치에 포함되지 않음.
- 관련 E2E: 107 통과, 3 건너뜀. 대상: 접근성, 홈 흐름, 일식/구름, 시각 동작, JavaScript 없는 환경. 전체 E2E 스위트를 다시 실행한 결과는 아님.
- Impeccable detector: 해당 수정 대상에서 진단 없음 (`[]`).
- 독립 finish reviewer: **ship**, 수정 범위 내 중대한 시각/탐색 결함 없음. 조건이었던 최종 E2E 통과도 충족.

## 시각 증거

`.impeccable/review/`의 desktop/mobile 전체·상단·하단 캡처와 browser-evidence.json.
전체 페이지 스크린샷에서는 fixed 배경이 첫 화면 영역에만 찍힌다. 하단 구름의 실제 지속 여부는 desktop-bottom.png / mobile-bottom.png가 증거이다.

## 한계

기존 공연 안내의 출처 최신성 문제는 이번 시각 수정 범위에서 재검증하지 않았다. 전체 `npm run verify` 통과를 의미하지 않는다. 실제 iOS Safari 단말 검사와 구름 애니메이션 전체 주기의 지각적 부드러움 검사는 수행하지 않았다. 배포·커밋·푸시는 하지 않았다.
